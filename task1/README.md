

`data/` - `dfS00`, все `dfSdXX`, медианные и прочие импутированные датасеты;
`tables/` - общая, классовая и признаковая статистика, сводки пропусков;
`figures/` - 16 компактных сравнительных рисунков: raincloud, матрица пар, heatmap, scatter-панно и объединённые UpSet-графики.

Пример выбора 50% пропусков для п. 1.8 и изменения оформления:

```powershell
python task1/solution.py --missing-rate 50 --seed 123 --alpha 0.35 `
  --point-size 12 --axis-color navy --major-ticks 5 --minor-ticks 2
```

```powershell
python task1/solution.py --help
```

## Соответствие пунктам

| Пункт | Реализация |
|---|---|
| 1.1 | `generate_dfS00`: 1000 объектов, 4 непрерывных признака, один столбец класса, заданная теоретическая корреляция A-B = 0.9. |
| 1.2 | Три CSV-таблицы: размерность/NaN/нули, статистика классов, describe + типы + skew + kurtosis. |
| 1.3 | Полу-violin (`cloud`) + jitter (`rain`) + boxplot с median, IQR и whiskers от min до max. |
| 1.4 | Матрица всех пар: scatter с цветами/маркерами классов и KDE-плотности классов на диагонали. Оформление управляется CLI. |
| 1.5 | Pearson и Spearman heatmap для всего датасета и каждого класса. |
| 1.6 | Ровно 0%, 1%, 2%, 5%, 10%, 20%, 50%, 80% случайных ячеек признаков становятся NaN; строится панно A+B. |
| 1.7 | Медианная импутация каждого `dfSdXX`, панно A+B и одно сравнительное полотно Pearson heatmap для всего набора/каждого класса. |
| 1.8 | Для выбранного `--missing-rate`: median, distance-weighted kNN, детерминированная регрессионная и стохастическая MICE-импутация; сравнение с `dfSd00` и исходным неполным набором. |
| 1.9 | Два объединённых UpSet-style полотна: каждый датасет показан отдельной строкой над общей матрицей всех 16 точных сочетаний признаков. |
| 1.10 | MNAR: значения C и D ниже собственной признаковой медианы заменяются на NaN, затем полностью повторяются 1.8 и 1.9. |
